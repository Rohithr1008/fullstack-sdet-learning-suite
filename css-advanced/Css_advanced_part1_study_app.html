1. CSS Animations vs Transitions & GPU Acceleration ⏱ ~30 min

🚩 Why it matters: Adding smooth animations improves user experience. However, animating properties like `width`, `top`, or `margin` forces CPU layout recalculations and causes jank (laggy 15 FPS rendering).

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of CSS Transitions vs Animations like a slide switch vs a full flipbook movie:\n• CSS Transition = Flipping a light switch from Off to On (Smooth change between State A and State B when hovered or clicked).\n• CSS Keyframe Animation = A full flipbook movie (Step-by-step control at 0%, 25%, 50%, 75%, 100% loop).\n• GPU Acceleration = Handing the drawing work to a super-fast GPU graphics card instead of making the CPU draw every single pixel by hand!

📖 Deep Conceptual Breakdown:

CSS Transitions trigger when a property changes state (e.g. `:hover`). Keyframe `@keyframes` animations run complex multi-step sequences independently.\n\nTo achieve 60 FPS silky smooth animations on mobile devices, ONLY animate GPU-accelerated CSS properties: `transform` (scale, translate, rotate) and `opacity`. Animating `width`, `height`, or `top` triggers CPU Layout recalculations.

Complete Example
/* High-Performance 60 FPS Card Hover Animation */
.card-3d {
  background: #1e293b;
  border-radius: 12px;
  padding: 24px;
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1), opacity 0.3s ease;
  will-change: transform; /* Signals browser GPU to promote layer */
}

.card-3d:hover {
  transform: translateY(-8px) scale(1.02); /* GPU accelerated */
  opacity: 0.95;
}

/* Multi-step Loading Spinner Animation */
@keyframes spinPulse {
  0% { transform: rotate(0deg) scale(1); }
  50% { transform: rotate(180deg) scale(1.1); }
  100% { transform: rotate(360deg) scale(1); }
}

.spinner {
  animation: spinPulse 1.5s infinite linear;
}
transform: translateY(-8px) — GPU-accelerated translation property avoiding CPU layout reflow.
will-change: transform — Optimizes rendering by promoting element to its own GPU compositor layer.
animation: spinPulse 1.5s infinite linear — Applies 360-degree loop keyframe animation.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Animating `top` or `margin-top` on hover, causing browser repaint lag.

Fix: Use `transform: translateY(-8px)` instead of `top` or `margin`.

🔮 Predict the Output / Behavior

Scenario: Which two CSS properties are GPU-accelerated for 60 FPS performance?

Answer: transform and opacity

🧪 Knowledge Check

Question: What is the purpose of prefers-reduced-motion media query?

✅ Answer: It detects if a user has enabled motion reduction in OS settings and disables heavy animations for accessibility.

Rationale: `@media (prefers-reduced-motion: reduce)` prevents motion sickness for neurodivergent/vestibular sensitive users.
