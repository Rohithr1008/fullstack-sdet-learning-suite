CSS Advanced — Part 1: Motion

Master CSS transitions, keyframes, timing curves, accessibility media queries, and high-performance compositing.

1. Transitions vs. Animations

Transitions smooth state changes (`:hover`, `:focus`). Keyframe animations create multi-stage loops without state triggers.

Interactive Demo 1: Button Hover Transition

.demo-btn {
  transition: transform 0.25s cubic-bezier(0.4, 0, 0.2, 1), background-color 0.25s ease;
}
.demo-btn:hover {
  transform: translateY(-3px);
  background-color: #153e75;
}

2. Loading Skeleton Animation

Use `@keyframes` for loading states to provide instant visual feedback to users during network requests.

Interactive Demo 2: Skeleton Shimmer

@keyframes loading-shimmer {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}

3. Accessibility & Reduced Motion

Respect user motion sensitivity using `@media (prefers-reduced-motion: reduce)`.

@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

4. Knowledge Check Quiz

Q1: Which properties run on the GPU compositor without triggering layout reflow?

Answer: transform and opacity. Avoid animating width, top, or margin.

Q2: How do you emulate reduced motion in Playwright?

Answer: await page.emulateMedia({ reducedMotion: 'reduce' });
