2. Design Token Hierarchy

Organize tokens into 3 distinct tiers:

  • Primitive Tokens: --blue-500: #1d4f91
  • Semantic Tokens: --color-surface-primary: var(--blue-500)
  • Component Tokens: --card-header-bg: var(--color-surface-primary)

3. Sass & PostCSS Preprocessing

4. Knowledge Check Quiz

Q1: What is the primary benefit of semantic tokens over primitive tokens?

Answer: Semantic tokens represent design intent (e.g., surface, border, action), enabling theme changes without modifying component code.
