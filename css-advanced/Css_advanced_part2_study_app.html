2. Stacking Contexts & Isolation

Avoid `z-index` collisions by using `isolation: isolate` on container elements.

.modal-backdrop {
  isolation: isolate;
  z-index: 1000;
}

4. Knowledge Check Quiz

Q1: Why does backface-visibility: hidden matter for 3D card flips?

Answer: It prevents the reverse side of the card face from rendering when rotated away from the viewer.
