Database Essentials — Part 2: SQL Joins & Relational Schema Design

1. Foreign Keys & Relationships ⏱ ~12 min

Foreign keys enforce referential integrity between parent and child tables (One-to-Many, Many-to-Many).

CREATE TABLE posts (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id) ON DELETE CASCADE,
  title VARCHAR(200) NOT NULL
);

2. SQL Joins (INNER, LEFT, RIGHT, FULL) ⏱ ~15 min

Combine rows from two or more tables based on a related column.

SELECT users.name, posts.title 
FROM users 
INNER JOIN posts ON users.id = posts.user_id;
