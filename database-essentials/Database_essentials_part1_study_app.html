Database Essentials — Part 1: Relational Databases & SQL

1. Tables, Rows, and Columns ⏱ ~10 min

Relational databases store structured data in tables with predefined columns and data types (INT, VARCHAR, TIMESTAMP).

CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL
);

2. CRUD Operations (INSERT, SELECT, UPDATE, DELETE) ⏱ ~12 min

SQL is the universal declarative language for data manipulation.

-- Select all active users
SELECT id, name, email FROM users WHERE active = true ORDER BY name ASC;
