📅 Step-by-Step Study Guide

🔹 Phase 1: Web & Version Control Foundations (Weeks 1–3)

  1. html-css-essentials — Learn semantic HTML5, CSS box model, flexbox, grid, and accessibility (a11y).
  2. git-essentials — Master git init, staging, commits, branch creation, merging, and GitHub Pull Requests.

🔹 Phase 2: Core Programming & Data (Weeks 4–7)

  1. javascript-essentials — Master JS fundamentals, DOM manipulation, closures, Promises, and Event Loop visualizers.
  2. database-essentials — Learn relational database tables, SQL queries (SELECT, INSERT, UPDATE), joins, and ORMs.

🔹 Phase 3: Backend & Type Safety (Weeks 8–11)

  1. node-express-essentials — Build Node.js servers, Express routing, middleware chains, REST controllers, and JWT auth.
  2. typescript-for-testers — Learn TypeScript primitives, interfaces, union types, tsconfig, and JS→TS migration.

🔹 Phase 4: Frontend Framework & Design Systems (Weeks 12–14)

  1. react-essentials — Learn React JSX, functional components, props, useState/useEffect hooks, and RTL.
  2. figma-to-dev — Learn Figma Dev Mode, mapping Auto Layout to CSS Flexbox, and design token hierarchies.

🔹 Phase 5: Automated Testing & Performance (Weeks 15–18)

  1. playwright-essentials — Master Playwright E2E testing, locators, Page Object Model (POM), network mocks, and CI.
  2. api-data-essentials — Learn REST API testing, authorization headers, JSON Schema validation, and k6 load testing.
  3. perf-basics — Optimize Core Web Vitals (LCP, INP, CLS), interpret Lighthouse scores, and audit DevTools.
  4. typescript-develop-test — Build and test a real Task Board app using full TS dev and Playwright loop.

🔹 Phase 6: Capstones & Career (Weeks 19–20)

  1. automation-portfolio — Launch and test against a complete Express + Vanilla JS Task Board portfolio application.
  2. phase-bc-fullstack-app — Launch and test against a full-stack React + Express + Vite capstone application.
  3. automation-tester-path — Review testing pyramid strategies, non-functional testing, career roadmaps, and SDET interview prep.
  4. css-advanced — Explore CSS motion keyframes, 3D transforms, container queries, and subgrid.
