automation-portfolio — Project & Test Suite Walkthrough

1. Application Architecture

This portfolio project demonstrates a full automated testing stack against a custom Task Board web application.

  • Backend: Express.js server providing REST API endpoints (server/index.js).
  • Frontend: Vanilla JS SPA with responsive card board UI (public/app.js).
  • Tests: Playwright API and E2E test suites (tests/).

2. Running the Tests & Local App

# Start the backend & frontend server
npm start

# Run Playwright E2E and API tests
npx playwright test
