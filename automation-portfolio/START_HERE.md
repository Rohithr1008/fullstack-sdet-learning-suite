# START HERE

Calm order. One step at a time.

1. **Install** — in this folder run `npm install`, then `npx playwright install chromium`
2. **Try the app** — `npm start` → http://localhost:4173 → login `demo` / `demo123`
3. **Run tests** — stop the server (or leave it; Playwright can reuse it) → `npm test`
4. **Open the report** — `npm run test:report`
5. **CI** — after push, check the Actions badge on GitHub and download the `playwright-report` artifact
