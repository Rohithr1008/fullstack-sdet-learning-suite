1. TestLeaf Day 15 Assignment: ServiceNow REST API Testing (POST, GET, PATCH, DELETE) ⏱ ~35 min

🚩 Why it matters: Testing backend REST APIs directly with Playwright APIRequestContext allows verifying database records, seeding test data, and testing microservices without UI overhead.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of API Testing vs UI Testing like ordering food at a restaurant:\n• UI Testing = Walking into the restaurant, sitting at a table, looking at the physical paper menu, talking to the waiter, and waiting 20 minutes for your food (slow).\n• API Testing = Calling the kitchen phone directly and saying "Deliver Order #42 to my address" (`request.post()`). The food arrives in 5 seconds (fast)!

📖 Deep Conceptual Breakdown:

This assignment covers the complete TestLeaf Day 15 ServiceNow Incident API automation suite:\n\n1. Create Incident (`POST /api/now/table/incident`): Pass JSON payload `{ short_description, description }`, verify HTTP 201 Created status, extract `sys_id` string.\n2. Get Incident Details (`GET /api/now/table/incident/{sys_id}`): Verify HTTP 200 OK and match created description.\n3. Update Incident (`PATCH /api/now/table/incident/{sys_id}`): Update urgency or state fields.\n4. Delete Incident (`DELETE /api/now/table/incident/{sys_id}`): Verify HTTP 204 No Content status.

Complete Example
import { test, expect } from '@playwright/test';

test.describe('TestLeaf Day 15: ServiceNow REST API Suite', () => {
  let sysId: string;

  // 1. POST: Create New Incident Record
  test('POST - Create New ServiceNow Incident', async ({ request }) => {
    const response = await request.post('https://dev12345.service-now.com/api/now/table/incident', {
      headers: {
        'Authorization': 'Basic ' + Buffer.from('admin:ServiceNowPass123!').toString('base64'),
        'Content-Type': 'application/json'
      },
      data: {
        short_description: 'Playwright Automated Incident Creation',
        description: 'TestLeaf Day 15 REST API Testing Assignment'
      }
    });

    // Assert HTTP status code 201 Created
    expect(response.status()).toBe(201);

    const responseBody = await response.json();
    sysId = responseBody.result.sys_id; // Extract unique record ID
    expect(sysId).toBeTruthy();
    console.log('Created Incident Sys ID:', sysId);
  });

  // 2. GET: Retrieve Created Incident Record
  test('GET - Retrieve Incident by Sys ID', async ({ request }) => {
    const response = await request.get(`https://dev12345.service-now.com/api/now/table/incident/${sysId}`, {
      headers: {
        'Authorization': 'Basic ' + Buffer.from('admin:ServiceNowPass123!').toString('base64')
      }
    });

    expect(response.status()).toBe(200);
    const body = await response.json();
    expect(body.result.short_description).toBe('Playwright Automated Incident Creation');
  });

  // 3. DELETE: Remove Incident Record
  test('DELETE - Delete Incident by Sys ID', async ({ request }) => {
    const response = await request.delete(`https://dev12345.service-now.com/api/now/table/incident/${sysId}`, {
      headers: {
        'Authorization': 'Basic ' + Buffer.from('admin:ServiceNowPass123!').toString('base64')
      }
    });

    expect(response.status()).toBe(204); // 204 No Content
  });
});
await request.post('...', { headers, data }) — Executes HTTP POST request using Playwright built-in APIRequestContext.
expect(response.status()).toBe(201) — Asserts HTTP 201 Created response status code.
sysId = responseBody.result.sys_id — Extracts record unique identifier from JSON response.
expect(response.status()).toBe(204) — Asserts HTTP 204 No Content response status for successful deletion.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Using `page.request` inside API-only tests instead of standalone `{ request }` fixture.

Fix: Use `{ request }` fixture directly for fast API testing without opening browser tabs.
