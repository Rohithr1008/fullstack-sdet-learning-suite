1. Git Branching, Checkout & Rebase Mechanics ⏱ ~30 min

🚩 Why it matters: Developing directly on the main branch breaks production when unfinished features or failing code are pushed. Git branches allow developers to work in isolated parallel universes.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of a Git Branch like a parallel universe timeline in a sci-fi movie:\n• Main Branch = The real world timeline where production users live.\n• Feature Branch = A parallel timeline created by a scientist (developer) to test a new invention without affecting the main real world.\n• Merging = Merging the parallel timeline back into the main real world timeline once the invention is proven 100% safe!

📖 Deep Conceptual Breakdown:

A Git branch is simply a lightweight moveable pointer to a specific commit. Creating a branch (`git checkout -b feature/login`) creates a new pointer without duplicating project files.\n\nWhen two developers edit the same line of code in the same file on different branches, Git cannot automatically guess which change is correct. This triggers a Merge Conflict. You must manually edit the conflict markers, choose the correct code, stage, and commit.

Complete Example
# 1. Create and switch to new feature branch
git checkout -b feature/user-auth

# 2. Make changes, stage and commit on feature branch
git add .
git commit -m "feat: implement user login form"

# 3. Switch back to main branch
git checkout main

# 4. Pull latest team changes from GitHub
git pull origin main

# 5. Merge feature branch into main
git merge feature/user-auth

# 6. Delete merged local feature branch
git branch -d feature/user-auth
git checkout -b feature/user-auth — Creates new branch feature/user-auth and switches HEAD to it.
git merge feature/user-auth — Merges commits from feature branch into current branch (main).
git branch -d ... — Safely deletes local feature branch after it has been merged.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Panicking when Git shows CONFLICT (content): Merge conflict in src/app.js.

Fix: Open the flagged file, look for conflict markers, edit to keep desired code, run git add, and git commit.

🔮 Predict the Output / Behavior

Scenario: What is a Fast-Forward merge in Git?

Answer: A merge where the target branch has no new commits since the feature branch was created, simply moving the branch pointer forward.

🧪 Knowledge Check

Question: What does git checkout -b my-branch do?

✅ Answer: It creates a new branch named my-branch and immediately switches your working directory to it.

Rationale: -b is shorthand for create and checkout.
