Git Essentials — Part 2: Branching, Merging & Conflict Resolution

1. Creating and Switching Branches ⏱ ~10 min

Branches allow isolated feature development without affecting the stable main branch.

# Create and switch to a feature branch
git checkout -b feature/login-page
# Or modern syntax:
git switch -c feature/login-page

2. Fast-Forward vs 3-Way Merges ⏱ ~12 min

Merge integrates changes from target branch into current active branch.

git switch main
git merge feature/login-page

3. Resolving Merge Conflicts ⏱ ~15 min

Conflicts happen when two branches modify the exact same lines in a file differently.
