Git Essentials — Part 3: Remotes & GitHub PR Workflow

1. Connecting to Remote Repositories ⏱ ~10 min

Remotes link your local Git repo to cloud servers like GitHub or GitLab.

git remote add origin https://github.com/username/repo.git
git push -u origin main

2. Pull Requests & Code Reviews ⏱ ~12 min

PRs facilitate team discussion, CI test execution, and code review prior to merging.

# Fetch remote updates and rebase
git fetch origin
git rebase origin/main
