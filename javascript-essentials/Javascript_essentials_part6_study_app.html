2. Unit & integration testing — Vitest/Jest

🚩 Why it matters: describe / it / expect are the grammar of JS tests.
import { describe, it, expect } from "vitest";
function add(a, b) { return a + b; }
describe("add", () => {
  it("adds", () => expect(add(2, 3)).toBe(5));
});
Unit = one function. Integration = several pieces together.

13. Advanced security (2) — RBAC, CORS, HTTPS

🚩 Why it matters: 403 = logged in but forbidden; tight CORS; HTTPS.
function requireRole(role) {
  return (req, res, next) => {
    if (req.user?.role !== role) return res.status(403).json({ error: "Forbidden" });
    next();
  };
}

15. Common hardening pitfalls

🚩 Why it matters: these undo Parts 5–6 overnight.
1. Skip CI "just once" → broken main
2. Print secrets in logs → rotate now
3. Fake-green tests → false confidence
4. Deploy on red CI → ship breakage
5. No /login rate limit → stuffing
6. Only E2E, no unit → slow/flaky net
Pyramid: many unit → fewer integration → thin E2E (Playwright Essentials).

🎯 Quiz

Merge with failing CI?

❌ Yes if you're in a hurry

16. Practice & auto-graded challenges

🚩 Why it matters: pure functions — the harness grades them instantly.

✏️ Practice: E1 CD deploys · E2 lint→test→build · E3 assert fails on mismatch · E4 403 · E5 GitHub Secrets · E6 429

🏅 C1 — testAssert(actual, expected) easy 5 min

Return true if strict-equal, else false.

💡 Hint

Use ===.

🏅 C2 — ciStepsOrder(steps) easy 8 min

Sort by .order ascending (lint→test→build→deploy).

💡 Hint

steps.slice().sort((a,b)=>a.order-b.order)

🏅 C3 — statusFromLint(ok) easy 5 min

Return "pass" if ok, else "fail".

💡 Hint

Ternary: ok ? "pass" : "fail"

🏅 C4 — tokenRefresh(accessExpired, hasRefresh) medium 10 min

If access still valid → "ok". If expired + refresh → "new_access". Else → "login".

💡 Hint

Check !accessExpired first.

🏅 C5 — rbacAllowed(role, action) medium 10 min

admin → any action; member → only "read"; else false.

💡 Hint

Two ifs, then return false.

🐞 Spot-the-Bug — final boss

Why it matters: catch CI/security mistakes before they ship.
Q1. CI is red but you merge to main anyway?

Don't — fix or revert; red means known breakage.

Q2. run: echo $JWT_SECRET in the workflow?

Never — secrets in logs are leaks; rotate.

Q3. Only Playwright E2E, zero unit tests?

Too slow/flaky alone — keep a test pyramid (unit + integration + thin E2E).

Q4. expect(true).toBe(true) as your only assert?

Useless — assert real behavior.

17. Answer key

function testAssert(actual, expected){ return actual === expected; }
function ciStepsOrder(steps){ return steps.slice().sort((a,b)=>a.order-b.order); }
function statusFromLint(ok){ return ok ? "pass" : "fail"; }
function tokenRefresh(accessExpired, hasRefresh){
  if (!accessExpired) return "ok";
  return hasRefresh ? "new_access" : "login";
}
function rbacAllowed(role, action){
  if (role === "admin") return true;
  if (role === "member") return action === "read";
  return false;
}
