💡 Map = any keys + insertion order. Set = unique values.

2. Generators

🚩 Why it matters: paginating large API results and async data streams (Mongo cursors, infinite scroll) are built on generators — `for await` is what consumes them.
💡 function* + yield. .next() → {value, done}.
function* countUp(){ yield 1; yield 2; yield 3; }
const g = countUp();
g.next(); // {value:1, done:false}

function* fib(){ let a=0,b=1; while(true){ yield a; [a,b]=[b,a+b]; } }
const f = fib();
f.next().value; // 0  (then 1, 1, 2...)

🎯 Generators quiz

Q1. What does `.next()` return?

❌ just the value — generators return an iterator result object

✅ {value, done} — {value, done}

Q2. What keyword marks a generator?

❌ async function — async is different

✅ function* — function* marks a generator

5. fetch

🚩 Why it matters: the React front-end talking to your Express API — every read/write to the server goes through `fetch`, and checking `res.ok` is non-negotiable.
📡 Talk to your Express API. Returns a promise; check res.ok.
async function getUsers(){
  const res = await fetch("https://api.example.com/users");
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return await res.json();
}
async function createUser(name){
  const res = await fetch("/api/users", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ name })
  });
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return await res.json();
}

🧪 Challenge solutions

C1 — countWords

❌ Using an object only and forgetting Map — Map is the right tool here

✅ Canonical solution — count with Map.set/get

function countWords(text){
  const m = new Map();
  for (const w of text.split(/\s+/).filter(Boolean)) m.set(w,(m.get(w)||0)+1);
  return m; // Map
}
C2 — slugify

❌ Leaving spaces and uppercase — slugs are lowercase hyphenated

✅ Canonical solution — lower + replace non-alnum + trim hyphens

const slugify = s => s.toLowerCase().replace(/[^a-z0-9]+/g,"-").replace(/^-+|-+$/g,"");
C3 — range generator

❌ Returning an array from a normal function — generators use function* and yield

✅ Canonical solution — function* range with yield

function* range(s,e){ for(let i=s;i<=e;i++) yield i; }
C4 — fetchWithTimeout

❌ Ignoring AbortController — timeouts need abort signals

✅ Canonical solution — AbortController + clearTimeout in finally

async function fetchWithTimeout(url,ms){
  const c=new AbortController(); const t=setTimeout(()=>c.abort(),ms);
  try{ const res=await fetch(url,{signal:c.signal}); if(!res.ok) throw new Error(`HTTP ${res.status}`); return await res.json(); }
  finally{ clearTimeout(t); }
}
C5 — freq

❌ Returning a Map when an object is required — match the expected return type

✅ Canonical solution — plain object tallies

function freq(text){
  const o={};
  for (const w of text.split(/\s+/).filter(Boolean)) o[w]=(o[w]||0)+1;
  return o;
}

🐞 Spot-the-Bug — final boss quiz

🚩 Why it matters: catch the classic MERN mistakes before they catch you.
Q1. What's the bug? const notes = Note.find();

Missing await — it's a promise, not data. Use await Note.find().

Q2. What's the bug? setNotes(notes.push(newOne))

push mutates and returns the length — use setNotes([...notes, newOne]).

Q3. What's the bug? React frontend calling http://localhost:3000 from a different port

CORS — add app.use(cors()) on the server.

Q4. What's the bug? fetch(url); const d = await res.json();

Never assigned the fetch result to res, and didn't check res.ok.

Q5. What's the bug? Note.findByIdAndUpdate(id, upd)

Returns the OLD doc — add { new: true } to get the updated one.
