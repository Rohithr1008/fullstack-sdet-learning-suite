## Interactive Quiz & Knowledge Check

### Section 1: JSX Basics

- [ ] **Q1:** Which HTML attribute name must be written as `className` when writing JSX?
  - A) `id`
  - B) `class`
  - C) `style`
  - D) `title`
  *(Answer: B — `className` is used because `class` is a reserved JavaScript keyword).*

- [ ] **Q2:** What happens if you do not provide a unique `key` prop when rendering an array list using `.map()`?
  - A) The app immediately crashes at runtime.
  - B) React issues a console warning and may experience reconciliation bugs during list reorders.
  - C) CSS styles are ignored.
  - D) Playwright tests cannot click the elements.
  *(Answer: B — React needs `key` props to track DOM nodes efficiently).*

### Section 2: Props & Composition

- [ ] **Q3:** How do child elements passed inside a component wrapper tag (e.g. `<Card><p>Hello</p></Card>`) get received inside the component?
  - A) Via `props.title`
  - B) Via `props.children`
  - C) Via `props.html`
  - D) Via `props.innerText`
  *(Answer: B — `props.children`).*

## Playwright Testing Tips for React JSX

- [ ] 1. Prefer selecting elements by accessible roles (`page.getByRole('button', { name: 'Submit' })`) or `data-testid` props (`<button data-testid="submit-btn">`).
- [ ] 2. Avoid relying on autogenerated CSS hash classnames (`.sc-bdVaJa`) produced by CSS-in-JS tools.
