1. What is React & The Virtual DOM Difference ⏱ ~30 min

🚩 Why it matters: Traditional DOM manipulation (`document.getElementById().innerHTML = ...`) forces the browser to recalculate layout and repaint the entire screen on every change. React uses a lightweight Virtual DOM to make UI updates 10x faster.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of the Real DOM like a massive 500-page paper encyclopedia on your bookshelf. If you fix 1 typo on page 200, reprinting the whole 500-page book is slow and wasteful!\n\nReact Virtual DOM is a fast digital draft copy on your computer screen. You fix the typo on the digital draft, React compares the draft against the printed book (Reconciliation / Diffing algorithm), and ONLY prints out page 200 to replace the 1 single page in the binder!

📖 Deep Conceptual Breakdown:

React is a component-based JavaScript library for building user interfaces. Instead of manually editing HTML strings in JavaScript, React components return **JSX** (JavaScript XML), allowing you to write HTML-like markup directly inside JavaScript code.\n\nWhen state changes in a React component, React creates a new Virtual DOM tree, computes the exact difference (diff) between the new Virtual DOM and the previous Virtual DOM, and batches the absolute minimum set of real DOM updates (patching).

🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Mutating state directly (e.g. `count = count + 1`) instead of calling the state updater function (`setCount`).

Fix: Never mutate state variables directly! Always use the setter function returned by `useState()` to trigger Virtual DOM re-renders.

🔮 Predict the Output / Behavior

Scenario: Why does React require using className instead of class in JSX markup?

Answer: Because `class` is a reserved keyword in JavaScript for defining ES6 classes.

🧪 Knowledge Check

Question: What algorithm does React use to calculate minimum real DOM updates?

✅ Answer: The Reconciliation (Diffing) algorithm.

Rationale: Reconciliation compares Virtual DOM trees to patch only changed nodes into the real browser DOM.
