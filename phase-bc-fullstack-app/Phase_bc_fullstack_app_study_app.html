phase-bc-fullstack-app — Full-Stack Integration Walkthrough

1. Capstone Architecture

This capstone project combines modern React component architecture with Node.js/Express backend APIs and Playwright automated tests.

  • Frontend: React (JSX, Hooks, CSS Modules) built with Vite (src/).
  • Backend: Express REST server with JSON seed data (server/).
  • E2E Tests: Playwright test suite (tests/e2e/).

2. Development & Testing Commands

# Run fullstack app in dev mode
npm run dev

# Execute Playwright E2E tests
npx playwright test
