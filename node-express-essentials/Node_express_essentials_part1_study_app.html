Node & Express Essentials — Part 1: Event Loop & REST APIs

1. The Node.js Event Loop & Non-Blocking I/O ⏱ ~12 min

Node.js executes JavaScript on a single thread using non-blocking I/O callbacks handled by libuv.

const fs = require('fs');

// Non-blocking asynchronous read
fs.readFile('data.json', 'utf8', (err, data) => {
  if (err) throw err;
  console.log('File content loaded!');
});

2. Express Routers & Middleware Chain ⏱ ~15 min

Middleware functions execute sequentially during the request-response cycle.

const express = require('express');
const app = express();

app.use(express.json()); // Built-in body parser middleware

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok', timestamp: Date.now() });
});
