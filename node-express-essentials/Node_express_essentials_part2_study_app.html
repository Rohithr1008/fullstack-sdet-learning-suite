Node & Express Essentials — Part 2: Layered REST API Architecture

1. Controller & Service Layer Pattern ⏱ ~12 min

Separate HTTP handling (Controllers) from business logic (Services) and database access (Repositories).

// routes/users.js
router.get('/:id', async (req, res, next) => {
  try {
    const user = await userService.getUserById(req.params.id);
    res.json(user);
  } catch (err) {
    next(err); // Pass error to global error handler
  }
});

2. Global Error Handling Middleware ⏱ ~10 min

Express error-handling middleware accepts 4 parameters (err, req, res, next).

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(err.statusCode || 500).json({ error: err.message });
});
