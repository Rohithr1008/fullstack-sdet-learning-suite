1. Understanding Core Web Vitals (LCP, INP, CLS) ⏱ ~30 min

🚩 Why it matters: Page speed directly impacts user retention and Google search rankings. Slow loading web pages cause 53% of mobile users to abandon a site.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of Core Web Vitals like a patient health checkup at a medical clinic:\n• LCP (Largest Contentful Paint) = How fast the main image or headline appears on screen (Target: < 2.5s).\n• INP (Interaction to Next Paint) = How fast the screen updates when you tap a button (Target: < 200ms).\n• CLS (Cumulative Layout Shift) = How much text jumps around unexpectedly while loading (Target: < 0.1 shift index).

📖 Deep Conceptual Breakdown:

Google Core Web Vitals measure real-world user experience metrics:\n\n1. LCP (Largest Contentful Paint): Measures loading performance. Marks the point when the main content of a page has likely loaded.\n2. INP (Interaction to Next Paint): Replaced FID. Measures page responsiveness by logging the latency of all click, tap, and key interactions.\n3. CLS (Cumulative Layout Shift): Measures visual stability. Caused by images without explicit width/height dimensions or dynamically injected ads.

Complete Example
// PerformanceObserver API: Measuring LCP in JavaScript
const observer = new PerformanceObserver((entryList) => {
  const entries = entryList.getEntries();
  const lastEntry = entries[entries.length - 1];
  console.log('LCP Value (ms):', lastEntry.startTime);
  console.log('LCP Element:', lastEntry.element);
});

observer.observe({ type: 'largest-contentful-paint', buffered: true });
observe({ type: 'largest-contentful-paint' }) — Observes LCP candidate elements as the browser renders.
lastEntry.startTime — Timestamp in milliseconds when the largest content element finished rendering.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Not setting explicit `width` and `height` attributes on `` tags, causing high CLS layout shifts.

Fix: Always provide width and height attributes or CSS aspect-ratio on images.

🔮 Predict the Output / Behavior

Scenario: What is the recommended threshold for a Good Largest Contentful Paint (LCP)?

Answer: Under 2.5 seconds.

🧪 Knowledge Check

Question: Which Core Web Vital metric measures unexpected layout shifts while a page loads?

✅ Answer: CLS (Cumulative Layout Shift)

Rationale: CLS quantifies visual stability by measuring how much elements shift position during load.
