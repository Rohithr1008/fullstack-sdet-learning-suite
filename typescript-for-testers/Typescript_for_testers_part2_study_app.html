1. tsconfig for testers

🚩 Why it matters: strict decides how many bugs the IDE catches.
{
  "compilerOptions": {
    "strict": true,
    "target": "ES2022",
    "module": "commonjs",
    "skipLibCheck": true
  },
  "include": ["tests/**/*.ts", "pages/**/*.ts"]
}
OptionTakeaway
strictBest default for test repos
includeWhat gets typechecked
skipLibCheckFaster CI; don't skip your code

3. Light POM annotations

🚩 Why it matters: typed fields document the page API.
export class LoginPage {
  readonly page: Page;
  readonly email: Locator;
  constructor(page: Page) {
    this.page = page;
    this.email = page.getByLabel('Email');
  }
  async login(email: string, password: string): Promise<void> { /* ... */ }
}
Return type of async login?

Promise<void>

Why readonly on locators?

Don't reassign after construction.
