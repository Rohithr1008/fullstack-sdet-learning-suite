1. What is Figma Dev Mode & How Designers Communicate Layouts ⏱ ~25 min

🚩 Why it matters: Front-end developers and SDETs receive design specs from UI/UX designers in Figma. Understanding how Figma measures padding, gap, typography, and colors prevents pixel-imperfect UI implementations.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Think of Figma like a digital architect blueprint for a house:\n• The UI Designer draws the house blueprint (button colors, screen layouts, fonts).\n• Figma Dev Mode is the measurements tape tool that lets you click any door or window on the blueprint to see exact dimensions in inches (pixels, rems, hex color codes).\n• The Developer is the builder taking those exact blueprint measurements and constructing the physical house in HTML & CSS!

📖 Deep Conceptual Breakdown:

Figma Dev Mode transforms visual design elements into inspectable CSS code snippets. When you inspect a frame in Figma Dev Mode, it exposes:\n\n1. Dimensions & Spacing: Width, height, padding (top, right, bottom, left), and gap between elements.\n2. Color Tokens: Hex codes (e.g. `#38bdf8`), RGBA values, or Design Tokens (e.g. `var(--color-primary)`).\n3. Typography: `font-family`, `font-size`, `font-weight`, `line-height`, and `letter-spacing`.\n4. Code Connect & Assets: Direct CSS/Tailwind exports and downloadable SVG/PNG assets.

Complete Example
/* CSS implementation extracted directly from Figma Dev Mode inspect panel */
.button-primary {
  display: flex;
  flex-direction: row;
  justify-content: center;
  align-items: center;
  padding: 12px 24px; /* Figma: Padding Vertical 12px, Horizontal 24px */
  gap: 8px; /* Figma: Item Spacing 8px */
  
  width: 180px;
  height: 48px;
  
  background: #0284c7; /* Figma Token: primary-600 */
  border-radius: 8px; /* Figma: Corner Radius 8px */
  border: none;
  
  /* Typography from Figma Specs */
  font-family: 'Inter', sans-serif;
  font-weight: 600;
  font-size: 16px;
  line-height: 24px;
  color: #ffffff;
}
padding: 12px 24px — Maps to Figma Auto Layout padding fields (12px top/bottom, 24px left/right).
gap: 8px — Maps directly to Figma Auto Layout "Item Spacing" between icon and text.
border-radius: 8px — Maps to Figma "Corner Radius" setting.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Hardcoding static pixel absolute positions (`top: 140px; left: 80px`) instead of using Flexbox.

Fix: Translate Figma Auto Layout directly into CSS `display: flex`, `gap`, and `justify-content`.

🔮 Predict the Output / Behavior

Scenario: If Figma Auto Layout has direction set to Vertical with 16px spacing between cards, what is the CSS equivalent?

Answer: display: flex; flex-direction: column; gap: 16px;

🧪 Knowledge Check

Question: What is the main purpose of Figma Dev Mode for developers?

✅ Answer: To inspect exact measurements, padding, colors, fonts, and CSS code snippets without altering the design canvas.

Rationale: Dev Mode provides read-only inspection tools tailored for code implementation.

2. Translating Figma Auto Layout directly into CSS Flexbox ⏱ ~30 min

🚩 Why it matters: Figma Auto Layout is literally CSS Flexbox built into a visual UI tool! Mastering the 1:1 translation between Figma controls and CSS properties makes frontend coding 5x faster.

💡 Explain Like I'm 5 (ELI5) / Beginner Analogy:

Imagine packing items inside a cardboard box:\n• Auto Layout Direction = Deciding whether to stack items vertically or line them up horizontally.\n• Hug Contents = Shrinking the box wrapper so it fits tightly around the items inside.\n• Fill Container = Stretching an item like an elastic rubber band so it takes up all available space inside the box!

📖 Deep Conceptual Breakdown:

Here is the exact 1:1 translation matrix between Figma Auto Layout and CSS Flexbox:\n\n• Figma Horizontal Auto Layout ➡️ `display: flex; flex-direction: row;`\n• Figma Vertical Auto Layout ➡️ `display: flex; flex-direction: column;`\n• Figma Item Spacing ➡️ `gap: Xpx;`\n• Figma Padding ➡️ `padding: top right bottom left;`\n• Figma Alignment (Top Left, Center, Space Between) ➡️ `justify-content` & `align-items`\n• Figma "Hug" Sizing ➡️ `width: fit-content;`\n• Figma "Fill Container" Sizing ➡️ `flex-grow: 1;` or `width: 100%;`

Complete Example
/* Card Component Translated 1:1 from Figma Frame Specs */
.card-frame {
  display: flex;
  flex-direction: column; /* Figma: Vertical Auto Layout */
  gap: 16px;              /* Figma: Item Spacing 16px */
  padding: 20px;          /* Figma: Padding 20px all sides */
  width: 100%;            /* Figma: Width set to Fill Container */
  background: #1e293b;
  border-radius: 12px;
}

.card-header {
  display: flex;
  flex-direction: row;    /* Figma: Horizontal Auto Layout */
  justify-content: space-between; /* Figma: Alignment Space Between */
  align-items: center;    /* Figma: Alignment Vertical Center */
}
flex-direction: column — Translates Figma Vertical Auto Layout frame.
justify-content: space-between — Translates Figma "Space Between" distribution setting.
width: 100% — Translates Figma "Fill Container" resizing mode.
🐞 Spot the Bug / Edge Case in this topic

Common Pitfall: Using fixed width (e.g. `width: 350px`) for a card set to "Fill Container" in Figma, breaking mobile responsiveness.

Fix: Use `width: 100%` or `flex-grow: 1` to honor the "Fill Container" fluid responsive behavior.

🔮 Predict the Output / Behavior

Scenario: What CSS property corresponds to Figma "Hug Contents" for width?

Answer: width: fit-content; (or allowing normal inline-block default behavior).

🧪 Knowledge Check

Question: How does Figma Auto Layout Item Spacing translate into modern CSS?

✅ Answer: gap: Xpx;

Rationale: The CSS gap property sets the exact space between flex items, matching Figma Item Spacing.
