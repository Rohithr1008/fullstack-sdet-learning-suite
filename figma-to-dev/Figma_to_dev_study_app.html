3. Dev Mode & Code Connect

// Figma Code Connect Mapping Definition
import { figma } from '@figma/code-connect';
import { Button } from './Button';

figma.connect(Button, 'https://figma.com/file/...', {
  props: {
    label: figma.string('Text Content'),
    variant: figma.enum('Type', { Primary: 'primary', Secondary: 'secondary' })
  },
  example: (props) => <Button variant={props.variant}>{props.label}</Button>
});

4. Knowledge Check Quiz

Q1: How does Auto Layout in Figma map to CSS layout rules?

Answer: Auto Layout operates identically to CSS Flexbox, controlling direction, item spacing (gap), and container padding.
