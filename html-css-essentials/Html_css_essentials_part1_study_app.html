1. HTML5 Semantic Tree & DOM Hierarchy ⏱ ~15 min

🚩 Why it matters: Playwright and browser accessibility engines read the HTML DOM tree. Non-semantic code (div soup) leads to brittle XPath locators.

HTML defines the structure of a web page as a hierarchical tree of nodes. Semantic elements (like header, main, nav, article) give meaning to elements, allowing screen readers and automated test locators (getByRole) to find controls deterministically.

2. Forms, Inputs & Accessibility Attributes ⏱ ~20 min

🚩 Why it matters: Form fields are the most tested components in web applications. Incorrect type or missing attributes break test automation.

Form controls must have appropriate input types (email, password, number, checkbox), required/disabled validation attributes, and ARIA state attributes (aria-expanded, aria-hidden, aria-invalid).

Complete Example
type="email" — Enforces mobile email keyboard layout and browser-native email regex validation.
disabled — Disables user interaction. Playwright page.click() will wait or throw if attempting to click a disabled button.
