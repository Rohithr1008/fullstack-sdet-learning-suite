# API & Data Essentials — Part 1 Plan

## Goal
Teach HTTP/REST foundations for testers: methods, status codes, request/response shape, assertions, and translating Postman into maintainable code.

## Sections
1. Why API testing (pyramid slice vs UI-only)
2. HTTP methods & status codes
3. REST resources & URLs
4. Headers, query params, JSON bodies
5. Assertions (status, headers, body)
6. Postman → code (fetch / Playwright `request` / supertest sketch)
7. First green smoke test
8. Common pitfalls
9. Practice exercises
10. Challenges
11. Answer key
